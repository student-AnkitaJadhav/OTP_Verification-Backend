OTP-based Email Verification System
This project demonstrates how to implement OTP-based Email Verification in a Node.js authentication system using MongoDB and Nodemailer. By the end of this tutorial, you'll have a fully functional system that ensures secure user verification through One-Time Passwords (OTPs) sent via email.


📌 Features
User Authentication: Register and log in users securely.
OTP Generation & Verification: Sends OTPs to users' email and verifies them for authentication.
MongoDB Integration: Stores user data and OTPs for easy verification.
Google SMTP Configuration: Secure email delivery using Google’s SMTP server.
Middleware: Implements security and validation middleware.
Complete Authentication Flow: A fully functional authentication system with registration, login, and OTP verification.




🚀 Tech Stack
Node.js and Express: Backend framework for building the server and API.
MongoDB: Database to store user and OTP information.
Nodemailer: For sending OTPs via email using Google’s SMTP service.
JWT (JSON Web Tokens): For token-based user authentication.
